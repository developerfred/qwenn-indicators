# Qwenn-Indicators
Repositório para indicadores técnicos exactos com QwenBend.

## Maintainer
**codingsh <codingsh@pm.me>**

## Description
BendLite implementations of technical indicators (RSI, MACD, Bollinger Bands)
with exact computation inside Qwen3.5-0.8B weights.

## Status
- [x] Estrutura do repositório (concluído)
- [ ] RSI indicator (próxima fase)
- [ ] MACD indicator (planejado)
- [ ] Bollinger Bands (planejado)

## Quick Start
```bash
# Instalar dependências
pip install -r requirements.txt

# Executar RSI (quando implementado)
python src/rsi.py --precos "70,72,68,65,67,71,73,70,69,72"
```
